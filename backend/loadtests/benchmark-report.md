# Load Test Baseline

Date: 2026-05-28

## Run configuration

- Tool: Locust 2.44.0
- Environment: local Django development server on `http://127.0.0.1:8000`
- Users: 8
- Spawn rate: 2 users/sec
- Duration: 45s
- Dataset: deterministic E2E seed (`e2e_alice` / `E2E_Test_123!`)

## Covered endpoints

- `POST /api/auth/login/`
- `GET /api/chat/conversations/`
- `GET /api/chat/messages/?limit=10`
- `GET /api/home/`
- `GET /api/recommendations/`
- `GET /api/users/search/?q=alina`

## Thesis-ready summary

The application sustained a representative authenticated read-heavy workload with zero request failures in the baseline run. Core user-facing APIs stayed in a low-latency range: recommendations p95 was 110 ms, chat messages p95 was 110 ms, conversations p95 was 76 ms, and home feed p95 was 210 ms. The aggregated p95 across all sampled requests was 240 ms.

## Notes

- These figures are a local development baseline, not a production SLA.
- The login endpoint is the slowest path in this run because it performs authentication and token issuance.
- The CSV files generated by Locust are stored under `backend/loadtests/results/`.
